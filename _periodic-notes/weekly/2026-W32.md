## Notes added

Only two concept notes are genuinely new this week, both in `concepts/ai-development/` and both syntheses rather than captures:

- **[[Self-Report Is Not Verification]]** — the week's centrepiece. Names a claim that several existing notes had been assuming without stating: a model's confidence is drawn from the same distribution as its output, so the errors are correlated and the self-assessment carries no independent information. It arrived out of the orphan audit, which is a good sign — the cluster was already there, it just had no name.
- **[[Four-Tier Memory Model]]** — working / episodic / semantic / procedural, each with a different store, retrieval mode and failure mode. Its useful move is negative: it argues *against* reaching for a vector database, since working memory needs no store and episodic memory is a query.

Either the note was drafted in June and committed late, or the date was backfilled. Not broken, just worth knowing which if you rely on the daily notes as a timeline.

## Suggested new connections

Pairs that share a claim but currently have no link in either direction. Ordered by how much the KB gains.

1. **[[Agent Autonomy Levels]] → [[Self-Report Is Not Verification]]** — the synthesis already argues autonomy should scale with available *external* verification, not with expressed confidence; the autonomy note is where someone actually choosing a level would read it, and the link runs only one way today.
2. **[[Four-Tier Memory Model]] ↔ [[Agents vs Long Context]]** — "just use a bigger context window" is precisely the working-memory-only answer the four-tier split exists to refute; each note is the other's strongest argument.
3. **[[Four-Tier Memory Model]] ↔ [[AI Second Brain Architecture]]** and **[[Building a Second Brain]] / [[PARA Method]]** — a second brain is a semantic-plus-episodic store for a human; the tier vocabulary would sharpen what those notes are actually proposing to store.
4. **[[Four-Tier Memory Model]] ↔ [[Context Distillation Loop - amnesia as a feature]]** — distillation is the working→semantic promotion step, i.e. the mechanism by which one tier feeds another. Neither note names the transition.
5. **[[Self-Report Is Not Verification]] ↔ [[Trust]]** — [[Trust]] is already flagged in the AI MOC as one of the new bottlenecks; "trust requires a signal independent of the party being trusted" is the same claim in the human register.
6. **[[Self-Report Is Not Verification]] ↔ [[Graduated Defense]]** — layered defence assumes each layer fails independently, which is exactly the correlated-error property a self-check violates. Good mutual sharpening.
7. **[[Evaluating Skills]] ↔ [[Definition of Done]]** — [[Evaluating Skills]] treats evals as a shipping gate and already links [[Testing Strategy]]; [[Definition of Done]] is the pre-AI name for the same gate and is currently missing from the chain.
8. **[[Agent Ergonomics]] ↔ [[Psychological Principles in UX Design]]** — ergonomics for agents and psychology for users are the same discipline aimed at different readers. The UX note is the only `concepts/ux/` note and stays weakly connected because of it.
9. **[[Conway and Intelligence Portability]] ↔ [[Agent as Device Shadow]]** — a device shadow is a portable, inspectable representation of state, which is a candidate answer to the intelligence-portability problem the Conway note poses and leaves open.
10. **[[Agent Autonomy Levels]] ↔ [[Two-Way Doors]]** — the autonomy note already links [[Reversibility-Calibrated Action]]; [[Two-Way Doors]] is the same reversibility logic and would complete the triangle. Lowest-value of the ten, listed for completeness.

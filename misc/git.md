
# Git with multiple SSH keys on the same machine

```bash
export GIT_SSH_COMMAND="ssh -i /Users/arinco/.ssh/id_ed25519_stevehoggnz_github -o IdentitiesOnly=yes -o IdentityAgent=none"
```

Or, you can use `git@github-stevehoggnz:SteveHoggNZ/skills.git`
